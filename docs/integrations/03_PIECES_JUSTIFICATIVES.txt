ENDPOINT CIBLE PROPOSE
POST /api/external/pieces-justificatives/deverser
Authentification par X-Company-Key et controle de l'entreprise liee.

REGLES
1. Verifier l'existence de l'operation exacte dans le dossier.
2. Verifier la correspondance VTE/ACH/AVO.
3. Verifier le type MIME, la signature PDF et la taille maximale.
4. Verifier SHA-256.
5. Meme cle + meme empreinte = rejeu sans doublon.
6. Meme cle + empreinte differente = conflit a refuser.
7. Renseigner piece_justificatif sans modifier les ecritures comptables.
8. La colonne Piece ouvre le document avec controle d'acces.

CONSTAT DU DEPOT
Le modele EcritureComptable possede piece_justificatif. Le endpoint de depot PDF n'a pas ete trouve dans les routes inspectees ; ce payload est une cible a implementer, pas une API deja disponible.
